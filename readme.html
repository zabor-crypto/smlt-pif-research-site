Исследование SMLT / ПИФ

Материалы и порядок чтения

Начать удобно с сайта: он связывает исходную позицию, источники риска, инструменты и решение по полной книге. Матрица ситуаций раскрывает, почему одинаковая позиция может требовать разных проверок. Короткая анимация и условный кредитный эпизод помогают проследить путь от сведений до возможного исполнения.

Документы академической версии 1.0 предоставляются в локальном комплекте. Веб-версия содержит самостоятельное объяснение проекта.

Два способа знакомства с проектом

Обычное чтение не ограничено временем. Для выступления предусмотрен браузерный маршрут из 12 сцен: десять минут, включая новый 40-секундный эпизод. Из подробностей можно вернуться к точной сцене с сохранённым временем; после возврата таймер находится на паузе.

Академические файлы SMLT PIF 1.0 хранятся в локальном комплекте: PPTX/PDF содержат 11 основных и 3 справочных слайда. Они исключены из публичной веб-версии. Браузерный маршрут содержит 12 сцен; редактирование сайта не меняет зафиксированные документы.

Что установлено в версии 1.0

Разработаны финансовая постановка, математическая структура и программный прототип. Сравнительная экономическая эффективность ещё не подтверждена; область технических и исторических свидетельств раскрыта в реестре.

Открытие без сети

Сохранённую веб-версию можно читать без сети: откройте index.html рядом с каталогом assets. Ссылки относительные; сведения о локальных академических документах не являются ссылками для скачивания.

Исходный код и воспроизводимость

Публичный выпуск программы готовится отдельно. До подтверждённой публикации здесь нет ссылки на репозиторий или утверждения, что код открыт.
